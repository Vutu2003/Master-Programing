# Master Program

Kho lưu trữ tài liệu, ghi chú, slide và mã nguồn phục vụ học tập chương trình thạc sĩ.

## Cấu trúc

- `docs/`: Tài liệu tham khảo và giáo trình.
- `notes/`: Ghi chú theo môn học.
- `slides/`: Slide trình bày theo môn học.
- `src/`: Mã nguồn và ví dụ thực hành.
- `template/`: Mẫu slide.
- `agents/`: Hướng dẫn soạn ghi chú và slide.

## Môi trường Python

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Hiện dự án chưa cần thư viện Python bên ngoài.
